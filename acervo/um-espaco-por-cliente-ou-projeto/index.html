Cansa de reexplicar o mesmo cliente ou projeto toda vez que abre uma conversa nova?

Dentro do Cowork existe o "Projects": um espaço isolado por caso ou cliente, com arquivos, instruções e memória próprios, separado das outras conversas. No site (claude.ai), a versão de Projects funciona parecido e é mais indicada quando o trabalho é pelo navegador. A vantagem não é só não repetir contexto — o Claude também só carrega o que é relevante daquele projeto pra cada pergunta, em vez de reler tudo, o que deixa a resposta mais rápida e o uso mais econômico.

Passo a Passo

1
Acesse o Claude
Acesse claude.ai ou o app, e entre com sua conta.
2
Crie um projeto
No Cowork, use o seletor "Projeto ou pasta", acima de onde você digita a mensagem. No site, clique em "Projects" no menu à esquerda e depois em "+ Novo projeto", dando o nome do caso ou do cliente recorrente.
3
Suba o que já existe daquele cliente ou caso
No site é arquivo por arquivo, ou selecionando vários de uma vez com Ctrl+A; no Cowork, "Adicionar uma pasta" resolve de uma vez só.
4
Use as instruções do projeto pro que é fixo
Guarde nas instruções do projeto só o que vale pra qualquer conversa dali — o contexto geral do cliente, um guia de estilo, uma regra fixa. Deixe pedidos específicos de cada tarefa direto na conversa, não nas instruções: instruções de projeto curtas funcionam melhor e custam menos.
5
A partir daí, toda conversa nova dentro do projeto já nasce com o contexto
Sem reexplicar do zero.
6
Regra de privacidade
Nunca coloque nome real de cliente, CPF ou qualquer dado que identifique alguém diretamente na conversa ou nos arquivos do projeto.

Exemplos da rotina:

  • Professor com turma fixa: cria um projeto "Turma 3B — Inglês" e sobe o plano de curso; toda aula nova já sabe o que já foi ensinado.
  • Empresário com cliente recorrente: cria um projeto com o nome do cliente e sobe orçamentos e e-mails anteriores; toda proposta nova já considera o histórico.
  • Gerente acompanhando a equipe: cria um projeto pra métricas do time e sobe os relatórios anteriores; toda atualização já compara com o mês passado.
